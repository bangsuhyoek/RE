# SubMate 앱 접근 권한 및 기능별 사전 고지서
(App Permissions & Prominent Disclosures)

**시행일자: 2026년 10월 19일** (2026년 10월 12일 공지)  
**버전: v1.3 (targetSdk 36 기준)**

본 문서는 구글 플레이스토어(Google Play)의 **사용자 데이터 및 민감한 권한 정책(Prominent Disclosure & Consent Requirement)** 및 정보통신망법 제22조의2(접근권한에 대한 동의)에 의거하여, SubMate 앱이 요구하는 시스템 접근 권한의 구체적인 이용 목적과 취급 방식을 이용자에게 명확히 안내합니다.

SubMate는 최소 권한의 원칙(Principle of Least Privilege)을 준수하며, 불필요한 시스템 오버레이(`SYSTEM_ALERT_WINDOW`)나 백그라운드 특수 포그라운드 서비스 권한을 일체 요구하지 않습니다.

## 1. 앱 접근 권한 체계 총괄

| 권한 항목 | 구분 | 수집 및 이용 목적 | 미허용 시 이용 제한 여부 |
| :--- | :---: | :--- | :--- |
| **알림 (POST_NOTIFICATIONS)**<br>*(Android 13+)* | **선택** | 구독 결제 예정일(D-3, D-1, 당일) 사전 단말기 로컬 푸시 알림 발송 (FCM 원격 푸시 미사용) | 구독 결제 알림 수신 불가 (앱 내 수동 확인만 가능) |
| **알림 접근 권한 (NotificationListener)**<br>*(BIND_NOTIFICATION_LISTENER_SERVICE)* | **선택** | 웹/앱 결제 시 카드사/은행/간편결제 앱 푸시를 감지하여 구독 정보 자동 입력 (온디바이스 로컬 파싱, 서버 미전송) | 자동 등록 알림 미제공 (수동 등록은 정상 가능) |
| **카메라 (CAMERA)** | **선택** | AI 인식을 위해 결제 영수증 실물 직접 촬영 | 직접 촬영 영수증 인식 불가 (사진 보관함 선택 또는 텍스트 입력 가능) |
| **사진 선택 (Photo Picker)** | **선택** | 결제 영수증 사진 또는 결제 완료 캡처 이미지 첨부 | 영수증 사진 인식 불가 (문자 복사 붙여넣기는 가능)<br>*(Android Photo Picker 적용으로 별도 저장소 접근 권한 불필요)* |
| **생체인증 (USE_BIOMETRIC)**<br>*(라이브러리 자동 결합)* | **선택** | 승인 카드에서 "이 금액 이하면 항상 허용" 범위를 설정할 때 지문·얼굴 또는 단말기 잠금으로 본인 확인 | "항상 허용" 범위 생성 불가 ("이번만 허용", "거절하고 해지"는 정상 이용 가능)<br>*(※ AndroidManifest.xml에 직접 선언하지 않고 androidx.biometric 라이브러리를 통해 안전하게 OS 인증 대화상자 호출)* |

*※ SubMate는 외부 브라우저 위에 강제로 그리는 오버레이 권한(`SYSTEM_ALERT_WINDOW`)과 특수 목적 포그라운드 서비스(`FOREGROUND_SERVICE_SPECIAL_USE`)를 요구하지 않으며, 앱 내 전용 해지 브라우저(`CancelBrowserActivity`) 안에서 안전하게 단계별 가이드를 제공합니다.*

## 2. 민감한 권한 및 기능별 '눈에 띄는 고지(Prominent Disclosure)' 전문

### [고지 1] 실시간 결제 감지 알림 접근 권한 (BIND_NOTIFICATION_LISTENER_SERVICE)
> **팝업 타이틀: ⚡ 실시간 결제 감지 권한 안내**
>
> 웹 브라우저나 외부 앱에서 구독을 결제했을 때, SubMate가 이를 자동으로 감지하여 원터치 등록 알림을 보내드리기 위해 **'알림 접근 권한'**이 필요합니다.
>
> 🔒 **데이터 보호 및 보안 약속**
> 1. **결제 알림만 선별 확인**: 신한, KB, 현대, 삼성, 토스, 카카오페이, 네이버페이, 구글 플레이 등 사전 등록된 금융/결제/앱스토어 앱의 알림만 처리합니다.
> 2. **개인 알림 절대 미수집**: 카카오톡 개인 대화, 일반 문자 메시지, 이메일 등 사적인 알림은 기본적으로 일체 수집하거나 들여다보지 않습니다. (문자·메신저 앱은 사용자가 설정에서 수동으로 켤 때에만 결제 문구 감지에 한해 선별 처리됩니다.)
> 3. **단말기 내부 로컬 처리 (서버 미전송)**: 알림 텍스트는 외부 서버로 전송되지 않으며, 스마트폰 기기 내부 메모리에서 결제 정보를 추출한 즉시 완전히 폐기됩니다. 요금 인상·유료 전환·해지 후 결제 경고가 뜬 건에 한해, 회원이 "증빙을 계정에 보관"에 따로 동의하면 서비스명·금액·일시·카드 끝 4자리 요약만 계정에 1년 보관합니다.
> 4. **자유로운 철회**: 본 권한은 스마트폰 설정 > 애플리케이션 > 특수 접근 권한 > 알림 접근 허용에서 언제든지 해제하실 수 있습니다.

### [고지 2] AI 해지 도우미 국외 이전 및 처리 동의 (선택)
> **팝업 타이틀: 🧭 AI 해지 도우미 이용 및 국외 이전 안내**
>
> 넷플릭스, 유튜브 등 복잡한 구독 서비스의 해지 화면을 이동할 때, 인앱 해지 브라우저에서 다음 이동 경로와 버튼을 자동으로 안내해드리기 위해 화면의 버튼 및 제목 텍스트를 인공지능 모델(Google Gemini API 유료 등급)로 분석합니다.
>
> 🔒 **데이터 보호 및 보안 약속**
> 1. **개인식별정보 마스킹**: 화면의 버튼 및 제목 텍스트(최대 60개)에서 회원의 이름, 이메일, 전화번호, 카드번호 등 개인 식별 정보는 완전히 지운(마스킹) 후 서비스명과 메뉴 텍스트만 전송합니다.
> 2. **유료 등급 AI 모델 학습 미사용**: Google Gemini API 유료 등급(Paid Services)을 사용하여 전송된 텍스트는 인공지능 모델 학습에 일체 사용되지 않으며, 분석 완료 즉시 SubMate 서버에서 파기됩니다.
> 3. **자유로운 선택**: 해지 시트에서 [AI 해지 도우미 함께 쓰기] 체크를 해제하거나 [평소 쓰는 브라우저로 열기]를 선택하면 AI 전송 없이 기본 해지 가이드만 이용할 수 있습니다.

### [고지 3] AI 영수증 이미지 분석 및 처리 위탁 동의 (선택)
> **팝업 타이틀: 🤖 AI 영수증 분석 이용 안내**
>
> 첨부하신 영수증 및 결제 내역 캡처 이미지는 최신 인공지능 비전 모델(Google Gemini API 유료 등급 우선, 실패 시 Google Cloud Vision 예비 연동)을 통해 암호화 전송되어 분석됩니다.
>
> 🔒 **데이터 보호 및 보안 약속**
> - 이미지 내에서 서비스명, 결제 금액, 결제일 정보만 추출하며, 기타 불필요한 개인 식별 정보는 저장되지 않습니다.
> - 분석이 완료된 이미지는 AI 연산 즉시 휘발성 소멸되며 모델 학습용 데이터로 재사용되지 않습니다.
> - 기능을 이용하지 않고 직접 수동으로 구독 정보를 입력하실 수 있습니다.

### [고지 4] "항상 허용" 범위 본인 확인 (생체인증 / USE_BIOMETRIC)
> **팝업 타이틀: 🔐 항상 허용 범위 만들기**
>
> 승인 카드에서 "이 금액 이하면 항상 허용"을 고르면, 회원 본인이 고른 것인지 확인하기 위해 지문·얼굴 인식 또는 휴대폰 잠금(PIN·패턴·비밀번호)을 요청합니다.
>
> 🔒 **데이터 보호 및 보안 약속**
> - 생체 정보는 휴대폰 운영체제(Android Keyguard / BiometricPrompt)가 직접 확인하며 SubMate는 생체 정보를 일체 받지 않습니다.
> - SubMate는 확인 성공 여부와 인증 방식(생체/잠금)만 기록합니다.
> - 본 기능은 `androidx.biometric` 표준 라이브러리를 통해 구현되어 매니페스트에 직접 위험 권한을 선언하지 않고 시스템 보안 환경에서 동작합니다.
> - "항상 허용"은 갱신 금액이 한도 이하일 때만 적용되며, 요금 인상·무료체험 유료 전환은 다시 묻습니다. 1년 뒤 자동 종료되며 언제든 해제할 수 있습니다.

### [고지 5] 결제 증빙 계정 보관 동의 (선택)
> **안내 위치: 결제 경고 카드의 "증빙을 내 계정에 보관할까요?" 상자, 내 계정 관리 > 결제 증빙 기록**
>
> - 보관 항목: 서비스명, 결제 금액·일시, 결제수단 이름과 카드 끝 4자리, 해지 처리 일시, 꾸독 승인 기록
> - 보관 기간: 증빙을 만든 날부터 1년 뒤 자동 삭제
> - 철회: 내 계정 관리에서 끄면 서버의 증빙을 즉시 삭제하며, 단말기 로컬 기록은 따로 지울 수 있습니다.
> - 동의하지 않아도 증빙은 기기에만 남고 다른 기능은 그대로 이용할 수 있습니다.

### [고지 6] AI 대화(챗봇 "꾸독") 및 AI 문장 해석 국외 이전 동의 (선택)
> **안내 위치: 챗봇 첫 진입 시 일회성 동의 카드, 챗봇 대화방 상단 메뉴 ([AI 데이터 전송 끄기] / [대화 지우기]), AI 문장 등록 화면**
>
> 챗봇 "꾸독"에게 질문하고 구독 관리 작업 제안을 받거나, 자연어 문장 입력을 통해 구독을 자동 등록하기 위해 입력 텍스트와 구독 현황 데이터를 미국 등 Google 데이터센터로 전송(국외 이전)하여 인공지능 연산을 처리합니다.
>
> 🔒 **데이터 보호 및 보안 약속**
> 1. **이전받는 자 및 목적**: Google LLC (Google Gemini API 유료 등급, 미국 등 소재) / 자연어 질문 답변 및 구독 데이터 추출
> 2. **이전 항목의 최소화**: 최근 대화 메시지(최대 12건), 구독 데이터 스냅샷(서비스명, 요금제, 금액, 결제일, 결제수단 별칭 등), 입력 자연어 문장(300자 이내). **카드 전체 번호, CVC, 계좌번호 등 금융 식별 정보는 일체 전송되지 않습니다.**
> 3. **유료 등급 AI 모델 학습 미사용**: 전송된 데이터는 인공지능 모델 학습에 사용되지 않으며, SubMate 서버는 대화 내용 및 스냅샷을 DB에 저장하지 않고 연산 즉시 폐기합니다 (사용자 ID별 일일 요청 횟수만 남용 방지 목적으로 90일 보관). Google의 시스템 로그는 55일 이내 보관 후 폐기됩니다.
> 4. **대화 내역 단말기 로컬 보관 및 삭제권**: 회원의 대화 내역은 본인 스마트폰 단말기 내부(localStorage)에만 저장되며, 화면 내 **[대화 지우기]** 버튼을 통해 언제든지 즉시 영구 삭제할 수 있습니다.
> 5. **동의 거부 권리 및 간단 모드 제공**: 본 동의는 선택 사항입니다. 동의하지 않거나 대화방 내 **[AI 데이터 전송 끄기]**를 누르면, 외부 전송이 전혀 없는 온디바이스 규칙 기반 **'간단 모드'**로 전환되어 동작하며 다른 모든 기능은 제한 없이 정상 이용할 수 있습니다.

## 3. 마케팅 정보 수신 동의 (선택)
1. **이용 목적**: SubMate 서비스 내 구독 요금 할인 프로모션, 신규 제휴 혜택, 이벤트 소식 전달
2. **전송 방법**: 단말기 로컬 알림
3. **철회 방법**: 앱 내 [설정 > 알림 설정 > 혜택 및 프로모션 알림] 토글 스위치 해제
