# SubMate 개인정보 처리방침

**시행일자: 2026년 10월 19일** (2026년 10월 12일 공지)  
**버전: v1.3**

"SubMate"(이하 "회사")는 정보주체의 자유와 권리 보호를 위해 「개인정보 보호법」 및 관계 법령이 정한 바를 준수하며, 이용자의 개인정보를 안전하게 처리하고 보호하기 위하여 다음과 같이 개인정보 처리방침을 수립·공개합니다.

---

### 1. 개인정보의 수집 및 이용 목적
회사는 다음의 목적을 위해 필요한 최소한의 개인정보를 수집·이용합니다. 처리하고 있는 개인정보는 다음의 목적 이외의 용도로는 이용되지 않으며, 이용 목적이 변경되는 경우에는 관련 법률에 따라 별도의 동의를 받는 등 필요한 조치를 이행합니다.

1. **회원 가입 및 계정 관리**: Supabase Google 로그인(OAuth) 연동을 통한 회원 식별, 가입 의사 확인, 계정 생성, 부정 이용 방지 (※ SubMate는 자체 아이디 및 비밀번호를 수집하거나 저장하지 않습니다.)
2. **구독 관리 핵심 서비스 제공**: 회원이 등록한 정기 구독 정보(서비스명, 요금제, 금액, 결제일 등)의 보관, 동기화, 통계 및 캘린더 분석 제공 (※ 게스트 모드 이용 시 모든 데이터는 단말기 내부에만 보관되며 서버로 전송되지 않습니다.)
3. **결제일 사전 푸시 알림 발송**: 결제 D-3, D-1, 당일 등 예정된 결제일에 맞춰 단말기 로컬 푸시 알림 발송 (※ 원격 푸시 서버 및 FCM 푸시 토큰은 사용하지 않습니다.)
4. **AI 영수증/결제 캡처 분석 서비스(선택, 별도 동의)**: 사용자가 등록을 위해 직접 첨부한 영수증 이미지 또는 결제 화면 캡처로부터 구독 데이터 자동 추출 (Google Gemini API 유료 등급 우선 연동, 실패 시 Google Cloud Vision 예비 연동)
5. **실시간 결제 감지(선택)**: 단말기에 수신된 결제 알림을 분석하여 신규 구독 등록 알림 제공 (기기 내 온디바이스 로컬 파싱, 기본 대상: 카드사·은행·간편결제·앱스토어 앱, 문자·메신저·이메일 앱은 사용자가 직접 켤 때만 처리)
6. **꾸독 에이전트 승인 기록(로그인 시)**: 결제 예정·요금 인상·유료 전환 승인 카드에 대한 회원의 결정과 "항상 허용" 범위를 기록해 여러 기기에서 같은 결정을 유지
7. **결제 증빙 보관(선택, 별도 동의)**: 요금 인상·유료 전환·해지 후 결제가 감지된 경우 환불 요청, 소비자 신고, 카드사 이의제기에 쓸 증빙을 회원 계정에 보관 (1년 보관 후 자동 삭제)
8. **AI 대화(챗봇 "꾸독") 및 AI 문장 해석 서비스 제공(선택, 별도 동의)**:
   - 챗봇 "꾸독": 자연어 대화 질문 답변 생성, 구독 추가·수정·알림 설정 작업 제안, 지출 요약 등 회원 맞춤형 구독 관리 지원
   - AI 문장 해석(`/api/agent`): 자연어 문장(300자 이내) 및 등록된 구독 이름 목록을 기반으로 구독 정보 추출 및 자동 등록 제안
   - (모든 AI 처리는 Google Gemini API 유료 등급을 통해 국외 이전 처리되며, 미동의 시 기기 내 규칙 기반 '간단 모드' 제공)
9. **AI 해지 도우미(선택, 별도 동의)**: 인앱 해지 브라우저에서 복잡한 해지 절차 진행 시, 화면 내 버튼·제목 텍스트(최대 60개, 개인정보 마스킹 처리)를 분석하여 다음 경로 안내
10. **온디바이스 구독 인사이트 알림**: 무료체험 종료, 연간 갱신, 미사용·중복 구독 등을 단말기 로컬에서 분석하여 사전 안내 푸시 발송 (외부 전송 없이 1일 최대 1회 단말기 로컬 알림)
11. **해지 난이도 및 다크패턴 제보(선택, 별도 동의)**: 회원이 제보한 해지 소요 시간, 단계 수, 다크패턴 유형 등을 익명 통계로 집계하여 다른 이용자에게 해지 난이도 정보 제공 (2년 보관, 서로 다른 5명 이상 제보 시에만 공개)

### 3. 개인정보의 보유 및 이용 기간
1. 회사는 법령에 따른 개인정보 보유·이용 기간 또는 정보주체로부터 수집 시에 동의받은 보유·이용 기간 내에서 개인정보를 처리·보유합니다.
2. **원칙**: 회원 탈퇴 시 수집된 모든 개인정보 및 구독 데이터는 **지체 없이 영구 파기**됩니다. 이용자는 앱 내 [계정 > 회원 탈퇴](`POST /api/account-delete`) 및 [데이터 내보내기(JSON)] 기능을 통해 언제든지 즉시 본인의 계정과 데이터를 영구 삭제하거나 다운로드할 수 있습니다.
3. **게스트 모드**: 기기 내부 저장소(localStorage)에만 보관되므로, 앱 삭제나 저장공간 데이터 삭제 시 즉시 파기됩니다.
4. **결제 증빙 보관(선택)**: 증빙 생성일로부터 **1년** 보관 후 자동으로 삭제됩니다. 회원은 앱 내 [내 계정 관리 > 결제 증빙 기록]에서 언제든 보관 동의를 철회하거나 개별/전체 증빙을 즉시 삭제할 수 있습니다.
5. **꾸독 에이전트 승인 기록**: 회원 탈퇴 시까지 보관합니다. "항상 허용" 범위는 생성일로부터 1년 후 만료되며 언제든 해제할 수 있습니다.
6. **해지 난이도 및 다크패턴 제보(선택)**: 제보 데이터는 생성일로부터 **2년**간 보관 후 파기됩니다. 통계 집계 목적으로 활용되며, 회원 탈퇴 시 제보자 식별 해시(`owner_hash`) 마이그레이션 적용 이후 생성된 본인 제보 건은 계정 탈퇴 시 즉시 함께 삭제됩니다. 단, 마이그레이션 적용 이전에 등록된 기존 제보 건은 시스템에 작성자 식별자가 일체 저장되지 않아 특정 회원의 데이터로 소급 식별 및 개별 삭제가 불가하며, 2년 보존 기간 경과 후 자동 폐기됩니다.
7. **AI 데이터(챗봇, 문장 해석, 해지 도우미, OCR)**:
   - **SubMate 서버**: 회원의 대화 내용, 문장 텍스트, 화면 버튼 텍스트, 구독 데이터 스냅샷을 서버 DB에 저장하지 않으며, API 응답 반환 및 연산 즉시 메모리에서 완전히 영구 폐기합니다.
   - **AI 남용 방지 기록**: 비정상적 과도 호출 및 어뷰징 방지를 위한 사용자 ID 기준 일일 호출 횟수 기록은 **90일** 보관 후 정기적으로 자동 삭제됩니다 (횟수만 기록되며 대화 내용은 미포함).
   - **단말기 로컬(기기)**: 대화 내역은 이용자 편의를 위해 스마트폰 내부 저장소(localStorage)에만 저장되며, 회원은 챗봇 화면 내 [대화 지우기] 기능을 통해 언제든지 직접 즉시 영구 삭제할 수 있습니다.
   - **수탁업체(Google LLC - Google Gemini API 유료 등급)**:
     - 회사는 Google AI Studio / Gemini API의 **유료 등급(Paid Services)**을 사용합니다.

### 7. 정보주체와 법정대리인의 권리·의무 및 행사방법

2. 권리 행사는 앱 내 [계정 > 회원 탈퇴](`POST /api/account-delete`) 및 [데이터 내보내기(JSON)] 메뉴를 통하여 즉시 직접 처리하실 수 있으며, 고객센터 이메일(`privacy@submate.app`)을 통한 서면·전자우편 요청 시에도 지체 없이 조치합니다.

4. AI 대화(챗봇 "꾸독")의 경우, 챗봇 대화 화면 내에서 언제든지 [AI 데이터 전송 끄기]를 선택하여 국외 이전을 거부(철회)할 수 있으며, [대화 지우기]를 통해 단말기에 보관된 대화 내역을 즉시 삭제할 수 있습니다. 동의 철회 시 온디바이스 '간단 모드'(외부 전송 없음)로 동작합니다.
5. 해지 난이도 제보의 경우, [내 계정]에서 언제든지 추가 제보 동의를 철회할 수 있습니다. 회원 탈퇴 시 `owner_hash` 마이그레이션 적용 이후 등록된 본인 제보 건은 탈퇴와 동시에 자동 영구 삭제되며, 마이그레이션 이전에 등록된 초기 제보 건은 시스템에 식별자가 저장되지 않아 소급 식별 삭제가 불가하여 2년 보존 기간 경과 후 자동 폐기됩니다.

### 8. 개인정보의 안전성 확보 조치
회사는 개인정보의 안전성 확보를 위해 다음과 같은 관리적·기술적 조치를 취하고 있습니다:
1. **Google OAuth 간편 인증 적용**: 자체 비밀번호를 수집·저장하지 않음으로써 비밀번호 유출 위험을 원천 차단하고 Google 보안 인프라를 활용합니다.
2. **저장 데이터 암호화 (Encryption at Rest)**: Supabase 클라우드 인프라를 통해 모든 데이터베이스 디스크 볼륨, 객체 스토리지, 백업 데이터에 대해 업계 표준 AES-256 암호화를 기본 적용합니다. (출처: https://supabase.com/security )
3. **단말기 로컬 처리 원칙 (On-Device Privacy)**: 실시간 결제 감지 알림의 원문은 서버로 전송되지 않고 단말기 기기 내에서만 파싱된 후 메모리에서 즉시 소멸됩니다. 게스트 모드 이용 시 모든 데이터는 단말기에만 보관됩니다.
4. **AI 데이터 최소화 및 학습 미사용 보증**:
   - AI 대화 및 문장 해석 시 카드번호 등 결제수단 식별번호는 전송 항목에서 원천 배제됩니다.
   - AI 해지 도우미 전송 시 이름, 이메일, 전화번호, 카드번호 등 개인식별정보는 마스킹 처리 후 전송됩니다.
   - Google Gemini API 유료 등급을 사용하여 고객 데이터의 AI 모델 학습 활용을 전면 차단합니다.
   - 회사의 서버는 대화 내용 및 구독 스냅샷을 저장하지 않고 응답 생성 즉시 폐기합니다.
5. **네트워크 전송 암호화**: 모든 통신 구간은 최신 TLS/HTTPS 보안 프로토콜을 적용하여 전송 중 데이터를 암호화합니다.
6. **접근 통제**: 승인 기록, "항상 허용" 범위, 결제 증빙 등은 행 단위 보안(Row Level Security, RLS)으로 회원 본인만 조회할 수 있도록 철저히 격리됩니다.
