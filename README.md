# SubMate

20대 다중 구독 사용자를 위한 AI 스마트 구독 관리 웹앱 MVP 프로토타입입니다.

## 실행

```bash
pnpm install
pnpm dev
```

브라우저에서 표시된 로컬 주소를 열고, 로그인 화면의 **둘러보기**를 선택하면 목업 데이터로 전체 플로우를 확인할 수 있습니다.

## 포함 범위

- React + Vite + Tailwind CSS 기반 인터랙티브 프로토타입
- 로컬 저장소 기반 구독·알림 상태 유지
- AI OCR 목업 등록, 결제 캘린더, 프로모션 탐색, 다이렉트 해지 가이드
- PRD 및 기능명세 문서
